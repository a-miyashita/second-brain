# second-brain User Manual

second-brain is a command-line tool. It collects your Slack conversations, your
Google Meet notes and your documents. It saves them on your computer, writes a short
summary of each item, and lets you search them. AI agents can also search them for you.

The tool has two names: `second-brain` and `sb`. They are the same program. This
manual uses `sb`.

## How to read this manual

- A line that starts with `$` in a code block is a command that you type. Do not type
  the `$`.
- Text in angle brackets, such as `<id>`, is a value that you replace with your own.
- A **Warning** tells you what to avoid. Read it before you do the step.
- A **Note** gives you extra information.
- Add `--help` to any command to see its options.
