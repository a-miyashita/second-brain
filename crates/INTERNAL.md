# Internal crate of second-brain

This crate is a part of [second-brain](https://crates.io/crates/second-brain), a
personal knowledge base for AI agents. It is published only because the
`second-brain` crate depends on it.

**It has no stability promise.** Its API can change in any release without notice.
Do not depend on it. To use second-brain, install the command-line tool:

```sh
cargo install second-brain --locked
```

Source code and documentation: <https://github.com/a-miyashita/second-brain>
